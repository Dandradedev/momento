# Site surpresa 🤍

Site estático, feito para abrir bem no celular e ser publicado no GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (por exemplo: `surpresa`), de preferência público.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação. O GitHub vai mostrar o link do site.
